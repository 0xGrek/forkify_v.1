# Forkify v1

Recipe search application built while practicing modern JavaScript modules, Parcel, Sass, API calls, MVC-style separation, bookmarks, pagination, and recipe upload UI.

## Run

```bash
npm install
npm start
```

The development server is handled by Parcel.

## Build

```bash
npm run build
```

## Status

Legacy JavaScript learning project, originally built during course practice and refreshed in 2026 for public portfolio presentation. The original app structure and tooling are preserved.

## Notes

- This repository contains the working app version.
- The separate `forkify` repository is a stub/duplicate and should not be used as the main project.
- No private API keys are committed in this repository.
